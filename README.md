I grew up using Wordperfect. My parents were both academics and they taught me how to format documents in Wordperfect with Reveal Codes. Reveal Codes is a fantastic feature that opened an inspector window and displayed text formatting, document feature and the like, in an easy-to-read way. Deleting the code would delete the formatting. 

Like many from this era, I resented the switch to Microsoft Word/Office which was commonly understood to be an inferior and unstable program, compared to Wordperfect. Its formatting built up with every change without being removed which makes it prone to misbehaving. And it lacks reveal codes. 

For decades users have attempted to reverse-engineer Wordperfect-style Reveal Codes for the .doc and .docx environment. So here it is! Because I wanted it!

This is a free Libreoffice Reveal Codes, Wordperfect style. The extension opens a side panel that displays the basic formatting, synced with the cursor position, and the formatting "blocks" can be deleted.


download the extension file oxt. double-click to install. open LibreOffice, View> reveal codes to open panel
